## How to Actually Trade (3 Simple Steps)

### Step 1️⃣: Open the Trade Page ⚡
```
When you open the app, you'll see menu in the sidebar:
✅ ⚡ Trade          ← Click this (it's FIRST now!)
   📊 Dashboard
   🔍 Screener
   ...
```

### Step 2️⃣: Fill the Form
```
┌─────────────────────────────────┐
│  Symbol: [ RELIANCE ▼ ]         │
│  Side:   [ BUY / SELL ]         │
│  Qty:    [ 1 ]                  │
│  Type:   [ MARKET / LIMIT ]     │
└─────────────────────────────────┘

Price: ₹2389.50 (auto-fetched)
Total: ₹2389.50
Margin: ₹100,000 ✅ (enough)
```

### Step 3️⃣: Click PLACE ORDER
```
✅ PLACE ORDER
│
├─> Order placed! Order ID: ORD-123456
├─> Confirmation: RELIANCE BUY 1 @ ₹2389.50
└─> Check Dashboard to see it
```

## Real Trading Workflow Example 🎯

### Scenario: You want to trade RELIANCE today

```
1. Open SCREENER (🔍)
   ├─ Set filters: RSI 25-75, Momentum >50
   ├─ Scan stocks
   └─ See RELIANCE in results with BUY signal ✅

2. Open DASHBOARD (📊)
   ├─ Check margin: ₹100,000 available
   ├─ Check open positions: None
   └─ Status: Ready to trade

3. Open OPTIONS BUILDER or GREEKS (optional)
   ├─ Analyze risk
   ├─ Calculate Greeks
   └─ Confirm strategy is good

4. Open TRADE (⚡) ← THE ACTUAL TRADING PAGE
   ├─ Symbol: RELIANCE
   ├─ Side: BUY
   ├─ Qty: 1
   ├─ Price: ₹2389.50 (auto-fetched)
   └─ PLACE ORDER ✅

5. Go back to DASHBOARD
   ├─ See new position: RELIANCE 1 @ ₹2389.50
   ├─ P&L: Updates in real-time
   └─ Monitor or close whenever you want
```
